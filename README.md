# 👓 Lens & Specs Optical Shop

A full-stack **Java Spring Boot** web application for an optical e-commerce store.  
It features a clean, responsive front end built with **HTML, CSS, Bootstrap, and Thymeleaf**, and a robust **MySQL + Spring Boot backend** to manage products, shopping cart, and customer feedback.

---

## 🌐 Overview
Lens & Specs is a demonstration of a modern e-commerce system for eyewear.  
It allows users to:
- Browse and view optical frames, lenses, and sunglasses.
- Add and remove products from a cart.
- Submit feedback or inquiries through a contact form.
- Experience a responsive layout that adapts to all devices.
